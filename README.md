# 物品管理ダッシュボード

**公開URL (Vercel):** [https://inventory-management-app-rd89.vercel.app/](https://inventory-management-app-rd89.vercel.app/)

## 1. 概要と開発の背景

高専ロボットコンテストでの優勝を目指すチームの運用において、「資材の在庫管理の属人化と、欠品による開発の遅延」が深刻な課題となっていた。ネジ一本や特定の電子部品が手元にないことは、その日の作業の完全な停止を意味する。

これまでの運用では、以下のような問題が発生していた。

* 誰が見ても「今なにが何個あるか」がわからない状態
* 在庫が最低限必要な数を下回ってから気づくため、部品の調達が後手に回る
* 保管場所、単価、購入先URLなどの情報が散在しており、補充判断に時間がかかる
* 管理情報が特定の担当者に依存し、そのメンバーが不在だと運用が止まる

この「あれがない、これがない」と騒ぎになってから発注する泥縄式の運用を脱却し、在庫情報を可視化して補充判断から発注までのリードタイムを最小化することが急務であった。大会に向けた開発の手を止めないため、5日間という短期間で本アプリケーションの設計と実装をゼロベースで行った。

## 2. 特徴と機能

本アプリケーションは、実際の運用フローに即した以下の機能を備えている。

**① 在庫と補充基準値の一元管理**
現在の在庫数と、補充の目安となる基準値を一つの画面で確認可能とした。これにより、チーム全員が同じ基準で在庫状況を把握できる。
`[スクリーンショット1: ダッシュボード全体、在庫一覧がわかる画像]`

**② 補充対象の自動ハイライト機能**
在庫が基準値を下回ったアイテムを視覚的に強調表示する。これにより、補充が必要な物品を即時に把握し、発注漏れを防ぐ。
`[スクリーンショット2: 基準値を下回り、ハイライトされているアイテムの画像]`

**③ 発注導線を短縮する情報統合**
保管場所、単価、購入先リンクを各アイテムのカード内に統合した。在庫不足の確認から実際の購入ページへの遷移がワンクリックで完了する。
`[スクリーンショット3: アイテム詳細またはカード内のリンク部分の拡大画像]`

**④ 直感的な管理画面**
管理者向けに、在庫アイテムやカテゴリの追加、編集、削除を容易に行える専用インターフェースを実装した。

## 6. 工夫した点・苦労した点

**運用環境の制約を考慮したMVP（必要最小限の機能）開発**
デプロイ先であるVercelの「読み取り専用ファイルシステム」という制約と、5日間という極端に短い開発期間の制約があった。そこで、まずは実際の現場で「情報を見る」という最も重要な課題を解決するため、ブラウザのローカルストレージとフロントエンドの表示状態を同期させる手法（useMemoとuseEffectの活用）を採用した。完全なデータベース連携は今後の課題としつつも、現状のチームの痛みを最速で取り除く現実的な設計を選択した。

## 7. 既知の課題と今後の展望

チームでの実運用をさらに強固なものにするため、以下の拡張を予定している。

* **外部データベース（Supabase）への移行:** データ保存先をクラウドデータベースへ切り替え、複数人での同時操作とデータの永続化を実現する。
* **認証機能の導入:** 管理画面へのアクセスに制限を設け、安全な運用体制を構築する。
* **操作履歴の記録:** 誰が、いつ、どの在庫を更新したかを記録し、確認できる機能を追加する。
